User Data Deletion Instructions — Tapugan Safety

Last updated: 2026-05-04

Tapugan Safety is an internal safety management system operated by Tapugan Ltd. (Israel). If you have used the system and wish to delete your personal data, follow the procedure below:

How to Request Deletion

  1. Send an email to mishaf1988@gmail.com
  2. Subject: "Tapugan Safety — Data Deletion"
  3. Body: your full name + the email address you used to log in
  4. (Optional) specify the data type you want deleted (profile only / action history / all)

Processing Time

Your request will be processed within 30 days from the date received. A confirmation will be sent via email.

What Will Be Deleted

  • User profile (name, email, phone)
  • Login history
  • Personal task assignments

What Is Retained (Regulatory Requirement)

Safety data with regulatory documentation value (e.g. NCR reports, risk assessments, accident investigations) is retained even after user deletion, but without linkage to personal identity. This retention is required by ISO 45001 and ISO 14001 standards and by Israeli workplace safety regulations.
