# רמת מאמץ לכל סוכן מתוזמן (10/11/2026)

מיכאל בשאלון: "בצע: רשימה מומלצת (מומלץ)". בעדכון של Claude Code אפשר לקבוע רמת מאמץ לכל סוכן שרץ בענן. פחות מאמץ = פחות מכסה, ומתאים לעבודה מכנית. הסוכנים שכותבים במסד, מחליטים בשביל מיכאל או מלמדים את העוזר נשארים במאמץ גבוה.
השינוי נעשה בדפדפן (C80 ב-`chrome-queue.md`): ל-`update_trigger` אין שדה מאמץ. המזהים ב-`ACCOUNT-INVENTORY.md`.

## נמוך (עבודה מכנית: קורא, מעביר, מדווח)
- בודק לתור המשימות למחשב (כל יום 09:37)
- תור משימות מ-Claude Code (א'-ה' 3 פעמים ביום)
- הדוור של הצ'אט במשרד (א'-ה' פעמיים ביום)
- נורות המפה
- יומן תוספות
- תזכורת פרסום ההדרכה
- רשת ביטחון לבקשות פיתוח
- משרד הסוכנים: עדכון בוקר
- מדידת מכסה יומית
- תפוגות שנתקעו אצל ספק
- מעקב הצעות מחיר
- סידור תעודות COA של שפכים

## בינוני (קורא מסמכים ומסכם, בלי החלטה)
- תיוק מהמייל ועדכון תוקף (פעמיים ביום; כותב תוקף, לכן לא נמוך)
- סריקת מיילים יומית
- דוח ציות חודשי (גבוה, ועובר ל-Fable 5.2, C81; לא בינוני), מסמכים חדשים בתיקיית הבטיחות, נוסח החוקים בנבו, מגמות מנתוני המפעל
- הדרכה שבועית מהשטח, רדאר רגולציה שבועי, הרדאר מלמד את העוזר
- עוזר החיסכון, מנהל השיווק, המגייס, בדיקת הניסוי השבועית

## גבוה (בלי שינוי)
- העוזר בוואטסאפ (בשני החשבונות), פיתוח מיידי, עובד לפי דרישה
- המפקח המדומה (ועובר ל-Fable 5.2, C81), בודק האיכות היומי, רטרו יומי, המאמן של העוזר
- בודק התוקף מול המסמכים, חוקר העוזר, חוקר ההמצאות, מודל ההעדפות

## איך יודעים שזה עבד
אחרי שבוע: דוח עוזר החיסכון מראה ירידה במכסה, ובמפת המערכת אין נורה אדומה חדשה בסוכנים שירדו. סוכן שהתחיל לטעות חוזר לרמה הקודמת.
