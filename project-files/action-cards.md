# כרטיסי פעולה: מה לזכור ברגע הפעולה

נבנה 25/11/2026 (מיכאל: "שיטה שלא יהיו פספוסים, שאתה תמיד תזכור לגשת למידע שזמין לך... בחיסכון בטוקנים"; DECISIONS 25/11/2026 "כרטיס כללים לפי פעולה ונמען"; המחקר: `project-files/research/action-cards-25-11-2026.md`).

**איך זה עובד:** כל שורה בטבלה היא כרטיס. כשפעולה מתאימה לעמודת "מתי", ה-hook `.claude/hooks/action-card.py` מזריק את "מה לזכור" לפני הפעולה (פעם אחת לכל כרטיס, ושוב אחרי דחיסת שיחה). כרטיס עם "אחר כך" נבדק בסוף התור ב-`action-complete.py`: אם אחרי הפעולה לא הופיעה פעולה שמתאימה לביטוי, התור נעצר פעם אחת עם תזכורת. לעוזר: השרת (`routine-db.js`) מחזיר את אותם כרטיסים בשדה `cards` בתשובה (`functions/_cards.js`, נבנה מכאן ב-`python3 tools/action-cards.py --write`).

**"מתי":** מילים מופרדות ברווח, `מפתח=ביטוי` (ביטוי רגולרי, בלי רווחים; `\s` לרווח). כולם חייבים להתאים. `tool` = שם הכלי; `op` = הפעולה של `routine-db.sh`; `to` = נמענים; `file` = שם, נתיב, קבצים מצורפים, תיקייה. בלי JSON שאפשר לקרוא: הביטוי נבדק על כל הפקודה.
**"אחר כך":** ביטוי שחייב להופיע בפעולה מאוחרת יותר באותה שיחה (ריק = אין). אפשר להתחיל בשמות כלים ונקודתיים, `Edit\|Write\|MultiEdit\|Bash:<ביטוי>`: אז נחשבת רק פעולה של הכלים האלה, הביטוי נבדק רק על הקלט שלה (קריאה או חיפוש לא נחשבים), ו-`Bash` נחשב רק כשהפקודה כותבת לקובץ שמתאים לביטוי (`>`, `>>`, `tee`, `sed -i`, `perl -i`). בלי קידומת: הביטוי נבדק על שם הכלי והקלט, כמו קודם.
**כרטיס חדש:** החלטה חדשה ב-DECISIONS.md נכנסת לכאן, או שורת `כרטיס: אין (<למה>)` ב-PR (`lessons-gate`). עד 500 תווים לכרטיס. הרטרו היומי מוסיף כרטיס לכל תיקון של מיכאל שלא היה לו כרטיס.
