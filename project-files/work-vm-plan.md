## מה המחשב יעשה

מחשב בענן שדולק תמיד, ועליו:
1. **Claude Code** (אותו כלי כמו השיחות האלה) מחובר לחשבון Claude של מיכאל.
2. **כרום עם התוסף Claude in Chrome**, מחובר פעם אחת לאתרים: Microsoft 365, Power Automate, Supabase, Cloudflare, GitHub, נבו, פורטלים של ספקים.
3. Claude Code שולט בכרום (`claude --chrome`). לפי התיעוד הרשמי, הוא "משתמש במצב ההתחברות של הדפדפן, ולכן ניגש לכל אתר שכבר מחוברים אליו" (code.claude.com/docs/en/chrome).
4. **משימה מתוזמנת** במחשב (Task Scheduler) שמריצה את Claude Code פעם או פעמיים ביום על התור `project-files/chrome-queue.md`, ומבצעת את המשימות שמיכאל אישר.

כך משימות שהיום מחכות לכרום במחשב של מיכאל רצות לבד: עדכון זרימות ב-Power Automate, בדיקות באתר החי, ועבודה בכמה אתרים ברצף.

- **הגודל:** B2s (2 מעבדים, 4GB זיכרון). מספיק לכרום ול-Claude Code. לא צריך יותר.
- **המחיר:** כ-0.056 דולר לשעה, כלומר כ-41 דולר לחודש כשהוא דולק תמיד. המקור הוא אתרי השוואה (cloud-mercato, azurespeed), לא מחשבון של מיקרוסופט. **לפני קנייה: לבדוק במחשבון של Azure** עם Israel Central ו-Windows. בשקלים זה בערך 150 ש"ח לחודש, לפי שער של כ-3.7 שקלים לדולר (הנחה שלי, לא נבדקה היום). יש גם דיסק וגיבוי, כמה דולרים נוספים.
- **למה ישראל:** שער המדינות ב-`_middleware.js` מכניס רק מישראל. בנוסף הנתונים (התחברויות, קבצים זמניים) נשארים בישראל.
- **למה Windows:** מיכאל לא מפתח. מחשב Windows נראה ומתנהג כמו המחשב שלו, ואפשר להיכנס אליו בלחיצה.

## מה לא נפתר גם עם המחשב

- **אימות דו-שלבי:** כשהתחברות פגה (פעם בכמה שבועות), צריך את הטלפון של מיכאל. Claude עוצר ומבקש, לפי התיעוד: "כשהוא מגיע לדף התחברות או CAPTCHA, הוא עוצר ומבקש".
- **כללי הארגון ב-365:** ייתכן שהארגון חוסם או מבקש אימות נוסף מהתחברות ממחשב חדש. נדע רק בהתחברות הראשונה.
- **מכסת השימוש ב-Claude:** אותו חשבון Claude. המחשב צורך מאותה מכסה כמו השיחות.
- **לא בדוק:** האם הרצה מתוזמנת בלי חלון פתוח (`claude -p --chrome`) עובדת. התיעוד מדבר על חלון כרום גלוי. אם לא, הקיצורים המתוזמנים של Claude in Chrome הם הדרך.

## אבטחה (המחשב יחזיק את ההתחברויות של מיכאל)

1. **החיבור מרחוק (RDP) לא פתוח לכל העולם:** רק מכתובת ה-IP של המפעל והבית, או דרך "Just-in-time access" של Azure.
2. **משתמש Windows עם סיסמה חזקה** ואימות דו-שלבי לחשבון Azure.
3. **עדכונים אוטומטיים** והצפנת דיסק (ברירת המחדל ב-Azure).
4. **בלי סיסמאות בקבצים.** ההתחברויות נשארות בכרום, כמו במחשב של מיכאל.
5. **הכללים של היום חלים גם שם:** אין שליחת מייל, אין מחיקה, כתיבה ב-365 רק עם "בצע" (CLAUDE.md, guard-365).
