## איך זה בנוי

המנהלים ומשאבי אנוש **לא נכנסים לאפליקציה**: מיכאל מפרסם ושולח להם את הקישור. לכן כל
התמונות הן הדף שהעובד פותח (`functions/api/talk.js`), כפי שהוא באמת, עם הטקסט של הטיוטות
`ind-0802` ו-`wk-tuganim` ועם שמות עובדים בדויים.

```bash
NODE_PATH=$(npm root -g) node tools/guide-talk-shots.mjs              # כל התמונות
NODE_PATH=$(npm root -g) node tools/guide-talk-shots.mjs w2-quiz      # אחת
NODE_PATH=$(npm root -g) node project-files/guide-training/build-pdf.js
PREVIEW=/some/dir NODE_PATH=$(npm root -g) node project-files/guide-training/build-pdf.js   # גם PNG לכל עמוד
```

הבנייה נעצרת על תמונה חסרה, עמוד שגולש ותו שאין במקלדת, כמו במדריך הנאמנים
(`project-files/guide-trustees/README.md` מסביר למה).

## עובדות בטקסט שבאות מהקוד

אם אחת מהן משתנה, לעדכן את המדריך ולבנות מחדש:

- הקישור השבועי תקף 14 יום (`TALK_TTL_DAYS`), הקישור לקבוצה יום אחד (`GROUP_TTL_DAYS`).
- הטופס החתום נשלח ל-`IND_HR` (hr-tap@tapugan.co.il) ולמיכאל, ומתויק ב-`IND_ROOT/<שנה>`.
- נושא המייל: "טופס קליטת עובד חדש חתום: (שם), (תאריך)" (`fileInduction`).
- ברשימת השמות רק עובדי המחלקה, ו"אני לא ברשימה" בראש הרשימה (`showTalk`).
- דף הקליטה מאחורי קוד משאבי אנוש, שהמכשיר זוכר שנה (`IND_CODE_DAYS`, `codeGate`). הצילום `w0-code.png`.

## לפני שליחה

הטיוטות `ind-0802` ו-`wk-*` עדיין **טיוטה** במסד. המדריך מראה אותן מפורסמות, עם מדריך.
לשלוח את המדריך אחרי שמיכאל פרסם, תרגם (כפתורי השפה מופיעים רק אחרי תרגום) והדפיס את ה-QR.
