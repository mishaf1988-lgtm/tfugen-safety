## 📦 רכיבי המערכת שנבנו בסשן

### 1. ה-Inbox האוטומטי של OneDrive (PRs #450-#459)
- `_odClassifyAndImport`: מסווג קובץ ב-Inbox (Llama Vision לתמונות, pdf.js+Llama text ל-PDFs).
- **Claude Haiku Vision כ-fallback** לתמונות עם אי-ודאות.
- מחלץ שדות (קוד ציוד, תאריכי תוקף, יצרן, וכו') ויוצר רשומה אוטומטית.
- מעביר את הקובץ לתת-תיקיה של הציוד (`/Apps/Tapugan Safety/Equipment Inspections/EQI-XXX - <שם> [תוקף ...]/`) עם דוח PDF אוטומטי.
- **סיווג ידני:** קבצים שה-AI לא בטוח → `/Inbox/_review/` עם תפריט בחירה ידני בתפריט OneDrive.

### 2. דוח PDF עברי תקין (PRs #443-#449)
**הפתרון הסופי:** במקום jsPDF text (שבר עברית 5+ פעמים) — html2canvas מצלם רינדור HTML מ-iframe, ו-jsPDF עוטף את התמונה ב-PDF. הדפדפן עושה את העבודה הקשה.

### 3. ריבוי קבצים בטופס ציוד (PRs #470-#471)
- שדה `attachments jsonb` ב-DB
- Drag-and-drop / multi-select בטופס
- כל הקבצים מסונכרנים ל-OneDrive (תוקן ב-PR #471 — היה bug שעצר ב-2)

### 4. מערכת מיילים אוטומטית (PRs #460-#469)
- **Microsoft Graph `/me/sendMail`** — שולח מהחשבון של המשתמשת

- **dispatcher אוטומטי** רץ 8 שניות אחרי load + visibilitychange + focus + 30min interval
