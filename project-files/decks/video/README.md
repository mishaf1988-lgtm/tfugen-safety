## איך בונים סרטון למצגת אחרת
0. **הכלי:** `tools/deck-video.py tts <scenes.json> <dir>` (הקראה לכל סצנה, מחכה דקה כשהקול מגיע למגבלה של 10 בדקה) ואז `tools/deck-video.py html <scenes.json> <dir>` (הקומפוזיציה, באותו עיצוב של סרטון העבודה בגובה). לפני ההפקה: `npx hyperframes snapshot --at <סוף כל סצנה>` ולבדוק בעין שאין טקסט שגולש.
1. `npm install --ignore-scripts hyperframes@0.9.19` בתיקייה זמנית (גרסה מ-06/11/2026), ו-`npx hyperframes init <name> -e blank --non-interactive --skip-transcribe`.
2. סצנות מתוך הבונה של המצגת (`../<topic>_deck.py`), בלי ניסוח חדש. מספרים בהקראה במילים ("שני מטר").
3. הקול: `routine-db` `tts_probe` עם `"model":"gemini","send":false,"b64":true` (הקול שמיכאל אישר לדף ההדרכה, 10/10/2026), סצנה אחת לכל קריאה.
4. משך כל סצנה = אורך ההקראה + 1.2 שניות. `npx hyperframes render -o out.mp4 -q standard` (כ-2 דקות הפקה לכל דקת וידאו).
5. כיווץ: `ffmpeg -c:v libx264 -crf 30 -vf scale=720:-2 -c:a aac -b:a 64k -ac 1`, כדי לעבור את מגבלת 8MB של `od_put_pdf`. העלאה עם `curl --data @file`.
