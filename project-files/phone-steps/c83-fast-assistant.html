מפתח לעוזר המהיר

שני חלקים קצרים, כ-3 דקות. בדפדפן (Chrome או Safari), לא באפליקציה של Claude. אם לא תעשה את זה, שום דבר לא נשבר: העוזר עובד כמו היום.

חלק 1 בדף של הסוכן החדש

לפתוח את דף הסוכן
  1. ללחוץ Edit.
  2. לגלול ל-Connectors, להוסיף Microsoft 365, וללחוץ Save.
  3. באותו דף, באזור API (או Triggers): ליצור טוקן חדש.
  4. להעתיק את הטוקן שמופיע. הוא מוצג פעם אחת בלבד.

ייתכן שהשמות בעיצוב אצלך מעט שונים. המילים Connectors ו-API יהיו שם.

חלק 2 ב-Cloudflare

לפתוח את ההגדרות באתר
  1. בחלק Production ללחוץ Add.
  2. סוג: Secret (לא Text).
  3. בשם להדביק את זה:
    ASSISTANT_FAST_FIRE_TOKEN
  4. בערך להדביק את הטוקן מחלק 1, וללחוץ Save.

לא לגעת באף משתנה אחר ברשימה.

לכתוב לClaude בשיחה: עשיתי. אני בודק לבד שהמחבר והטוקן נשמרו, מפרסם את האתר מחדש ושולח שאלת בדיקה. לא צריך לבדוק כלום בעצמך.
