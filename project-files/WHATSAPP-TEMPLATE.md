# תבנית WhatsApp להתראות בטיחות

**למה זה קיים:** ב-21/09/2026 הגיעה ההתראה הראשונה בוואטסאפ, וכתוב היה בה
**"🚨 תקרית בטיחות"** ו**"נא לטפל מיידית"**. מיכאל: «רשום תקרית בטיחות לא נכון,
צריך לנסח יותר רגוע שלא יחשבו שמשהו מאוד דחוף. מפגע או ליקוי ולא תקרית.»

הוא צודק. מטף שחסרה לו פלומבה אינו תקרית, והמילה הזו מייצרת בהלה שתגרום
לאנשים להפסיק לקרוא את ההתראות. אבל **הטקסט הקבוע הזה שייך לתבנית מאושרת של
Meta ואי אפשר לשנות אותו מהקוד** - התבנית `tfugen_incident_alert` אושרה בזמנו
לתקריות, והיא משמשת כאן כברירת מחדל רק כי אין אחרת.

**הפתרון: ליצור תבנית חדשה.** הקוד כבר מחפש אותה בשם `tfugen_safety_report`,
מנסה אותה ראשונה, ונופל לישנה רק אם היא לא קיימת. **ברגע שהיא מאושרת היא
נכנסת לשימוש בלי שינוי קוד ובלי פריסה.**

---

## מה ליצור

**איפה:** Meta Business Suite → WhatsApp Manager → Message Templates → Create template
(או https://business.facebook.com/wa/manage/message-templates/)

| שדה | ערך |
|---|---|
| Name | `tfugen_safety_report` |
| Category | **Utility** (לא Marketing) |
| Language | **Hebrew / עברית** |

**Body** - להעתיק בדיוק, כולל המספרים בסוגריים המסולסלים:

```
דיווח בטיחות חדש

מדווח: {{1}}
סוג: {{2}}
מיקום: {{3}}
הממצא: {{4}}

לצפייה ולטיפול במערכת.
```

**דוגמאות לערכים** (Meta מבקש דוגמה לכל פרמטר לפני אישור):

| פרמטר | דוגמה |
|---|---|
| {{1}} | דני כהן |
| {{2}} | ליקוי בסיור נאמן: עמדות כיבוי אש |
| {{3}} | אולם ייצור, מסוע 3 |
| {{4}} | מטף ליד דלת 4, פלומבה קרועה |

**Footer** (לא חובה): `תעשיות תפוגן, מערכת ניהול הבטיחות`

**Header ו-Buttons**: להשאיר ריקים. הקוד שולח body בלבד, וכפתור שהתבנית מגדירה
ולא נשלח עלול להיתקע באישור.

---

## למה דווקא הניסוח הזה

- **אין "תקרית" ואין "מיידית".** דיווח שגרתי נראה שגרתי. כשיש באמת סכנה מיידית,
  הנוהל הוא טלפון לממונה ולא דיווח במערכת - כך כתוב גם במדריך לנאמנים.
- **"סוג" אומר מה זה**: ליקוי בסיור או כמעט ונפגע. בתבנית הישנה השורה הזו נשאה
  את המיקום, והמיקום נשא את שם המשימה.
- **ארבעה פרמטרים ולא שלושה**, כדי שלמדווח תהיה שורה משלו. בתבנית הישנה השם
  נדחס לתוך שורה אחרת.
- אין אימוג'י בפתיחה. `🚨` בראש הודעה קורא כמו אזעקה.

---

## אחרי האישור

אין מה לעשות. הקוד מנסה את `tfugen_safety_report` בכל שליחה, ועובר אליה ברגע
ש-Meta מאשרת. האישור לוקח בדרך כלל דקות עד יום.

**לבדוק:** מודולים → 🔔 הגדרות התראות → 🧪 בדיקה. אם ההודעה שמגיעה פותחת
ב"דיווח בטיחות חדש" - זה עבד.

**אם משנים את נוסח התבנית ב-Meta** - לוודא שסדר הפרמטרים נשאר מדווח / סוג /
מיקום / ממצא, או לעדכן את `sendWhatsApp` ב-`functions/api/trustee-notify.js`
יחד איתו. `tests/harness/trustee-notify-test.mjs` מקבע את הסדר הזה.
