# ענף: עבודה בגובה והיתרים

נטען לבד כשמזכירים את הנושא (`index.json`). חוק מלא נמצא במקום שמצוין בסוגריים; כאן רק השורה וההפניה.

## לפני שמכינים מסמך (כל ענף)
1. **קודם הקיים:** לקרוא את התיקייה (`read_resource` על התיקייה) ולחפש טופס מבוקר באינדקס (`project-files/iso-forms-index.md`). מסמך חדש רק אם אין.
2. **הטופס המבוקר של המפעל:** קובץ ה-Word המקורי (לוגו, טבלת כותרת, מספר טופס, "עמוד X מתוך Y", ת. עדכון). לא בונים מאפס ולא מ-HTML (01/11/2026: טופס 08.01 בלי לוגו). מילוי: `tools/od-get.sh` + `tools/form-fill.py` (Word ו-PDF, בדיקת לוגו וכותרת), ואם אין soffice: `od_pdf`. ה-PDF שנשמר בתיקייה: `od_put_pdf` ל-Word ואז `od_pdf` (Microsoft, כמו הדפסה מ-Word).
3. **Word וגם PDF**, באותו שם, באותה תיקייה (DECISIONS 24/10/2026).
4. **בדיקה לפני "נשמר":** לקרוא את הקובץ שנשמר ולכתוב מה בדיוק שונה. השרת דוחה "נשמר" בלי זה (`claimGate`).
5. **גרסה שהוחלפה:** `od_trash` מיד, בלי לשאול; בתיקייה נשאר קובץ תקין אחד (DECISIONS 01/11/2026). קובץ של אדם: לא נוגעים.
