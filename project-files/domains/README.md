# ענפי העבודה

מיכאל, 01/11/2026: "שתפצל את כל העבודות שלנו לענפים, כדי שלא תבלבל בין ענף לענף. לכל אחד יש את החוקים שלו, את המסמכים שלו ואת הדברים שלו", "גם לך וגם לעוזר", "גם נושא החוקים... שלא תשכח שום דבר".

- **איך נטען:** מילה מ-`index.json` בהודעה של מיכאל. אצל Claude: `.claude/hooks/domain-load.py` מכניס את ראש הקובץ להקשר. אצל העוזר: השרת מוסיף שורת `domain` להודעה (`functions/_domains.js`, נבנה מ-`index.json` ב-`python3 tools/domains-build.py`). נבדק ב-`tests/harness/domains-test.py`.
- **משימה לא ברורה, או שלא שייכת לענף** (מיכאל, 01/11/2026: "אתה צריך להציע ענף, או, אם הענף לא קיים, להציע ליצור ענף חדש. זה חלק מהחוקים"): שאלון (העוזר: כפתורים) עם הענף המתאים, או "בצע: ענף חדש <שם>". ענף חדש = קובץ כאן באותו מבנה, שורה ב-`index.json`, והרצת `tools/domains-build.py`.
- **מבנה קובץ ענף** (עד 80 שורות, נאכף): "לפני שמכינים מסמך" בראש, ואז `## תיקיות`, `## טפסים מבוקרים`, `## חקיקה`, `## החלטות`, `## לקחים`, `## במערכת`. חוק נכתב במקום אחד: בענף שורה קצרה והפניה (DECISIONS, לקח), לא העתקה.
- **אחרי משימה בענף:** מה שנלמד נכנס לקובץ הענף באותו PR (Claude), או `learn` עם `source` שמתחיל בשם הענף (העוזר).
- **טופס מבוקר (כל ענף):** מילוי: `tools/od-get.sh` + `tools/form-fill.py` (Word ו-PDF, בדיקת לוגו וכותרת), ואם אין soffice: `od_pdf`. ה-PDF שנשמר בתיקייה: `od_put_pdf` ל-Word ואז `od_pdf` (Microsoft, DECISIONS 24/10/2026).
