## 🏗 ארכיטקטורה אוטונומית — איך זה עובד

```
משתמש שוכח סיסמה
   ↓
"שכחתי סיסמה?" במסך login → מקליד שם משתמש → "שלח סיסמה חדשה"
   ↓
POST /api/self-recovery (anonymous)  ← קוד ב-functions/api/self-recovery.js
   ↓ [שרת]
1. lookup ב-app_users (active=true)
2. rate-limit (1 reset/5 min/username)
3. find Auth user (email = username@tfugen.local)
4. generate סיסמה זמנית 8 תווים (alphanumeric)
5. update Supabase Auth: password + must_change_password=true
6. במקביל:
   a. send mail דרך Microsoft Graph CLIENT_CREDENTIALS
      → from: sviva@tapugan.co.il
      → to: user.email (real email מ-app_users)
   b. send WhatsApp דרך Meta Cloud API + template tfugen_password_reset
      → to: user.phone (מ-app_users)
7. audit row ב-password_reset_requests עם status=completed
   ↓
המשתמש מקבל מייל + WhatsApp תוך שניות
   ↓
בכניסה הראשונה → modal force-change-password (PR #506)
```

יצירת משתמש חדש (`POST /api/create-user`) → אחרי שהאדמין מקבל את ה-credentials במודאל, אוטומטית קוראים ל-`POST /api/send-credentials` (admin-gated) → אותו flow שליחה (mail + WA template).

## ⚠️ הערות קריטיות ללמידה

### דבר 1 — ההיסטוריה המכאיבה של ה-bnav
לאורך הסשן היו 7 ניסיונות לתקן באג ב-bnav באייפון Safari (PRs #483-#491). **כולם נכשלו**. בסוף הוחלט לעשות revert מלא + selective re-apply בלי השינוי הסמנטי `<div class="main">` → `<main>`. **המסקנה: השינוי הזה הוא החשוד שגרם לבאג.**

🛑 **לעולם לא לחזור ל-`<main>` semantic** בלי לבדוק היטב את ה-bnav באייפון בכל שלב.

### דבר 2 — Coworker (Copilot agent) זהירה
לאורך הסשן Coworker (סוכן AI שעוזר ל-sviva מהצד שלה) הייתה זהירה במיוחד. היא:
- מצאה (וטעתה לגבי) "Stop Claude" injection בקובץ — היה false positive, אבל הזהירות נכונה
- סירבה להזין סודות מטעמה — נכון
- דרשה אישור פרטני לכל פעולה רגישה — נכון

📌 **המשך לכבד את הזהירות הזו**. אם Coworker עוצרת — בדוק ביסודיות לפני שאתה אומר לה להמשיך.

### דבר 3 — אוטונומיה אבל עם אחריות
האוטונומיה המלאה (Phase 3) מאפשרת ל-`/api/self-recovery` לאפס סיסמאות **בלי שום אישור ידני**. השמירה היא:
- Rate-limit (5 דקות בין resets לאותו username)
- "אין enumeration" (תמיד 200 בתגובה — אי אפשר לדעת מה username חוקי)
- audit row לכל reset

🛑 לפני שמוסיפים פיצ'רים אוטונומיים נוספים — לוודא שיש את אותן 3 הגנות.
