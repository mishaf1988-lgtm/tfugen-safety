# מצגת לקורס מדריכי בטיחות: "מתפוח אדמה למקפיא"

מיכאל, 16/11/2026: מצגת של 12 שקפים לקורס מדריכי בטיחות, שמדגימה שיטות הדרכה דרך ייצור צ'יפס קפוא (כמו בתפוגן). לא חלק מהאפליקציה.

## מה יש כאן
- `מצגת-צ'יפס-קפוא-שיטות-הדרכה.pptx`: הגרסה האחרונה שנשלחה למיכאל.
- `build2.js`: בונה את השקפים (pptxgenjs, react-icons, sharp). מריצים מתיקייה עם `npm install pptxgenjs react-icons react react-dom sharp`, ויוצא `fries-raw.pptx`.
- `fx.py`: מוסיף מעברים ואנימציות: צורה ששמה `aniK_*` נכנסת בקליק מספר K; `num`, `bad`, `ring`, `st*` נכנסות בהגדלה. `python3 fx.py fries-raw.pptx fries.pptx`, ואז `zip -dq fries.pptx '*/'`.

## מה סוכם עם מיכאל (שאלונים, 16/11/2026)
- קובץ PowerPoint, 12 שקפים, 10 דקות, בלי פעילות פיזית מלבד תפוח אדמה וסכין קילוף.
- נושא: צ'יפס קפוא (לא חטיף בשקית). הדרכה על הצ'יפס בשיטות, וחשיפה בסוף "מה עשיתי לכם".
- מבנה לפי הקורס (מבנה ההרצאה): פתיח וואו (1-2), הצגה עצמית (3), חזון (4), מטרות (5), ואז התוכן.
- מסר שתול: "כל שלב בקו עובר בדיקה", תגית ירוקה בשקפים 6-10, נחשף בשקף 12.
- נתונים מהתעשייה עם שורת מקור בשקף; לא נתוני הקו של תפוגן. ויתרנו על שקף הסיפור (French fries) ועל "מצאו את הפגום".

## פתוח
- מיכאל לא אישר עדיין שהאנימציות רצות ב-PowerPoint אמיתי (F5).
- התואר בשקף 3 "מנהל בטיחות ואיכות סביבה": לאשר מול מיכאל.
- נתונים אמיתיים מהקו של תפוגן (טמפרטורת טיגון, הקפאה, לחץ קילוף), אם מיכאל ישיג.
