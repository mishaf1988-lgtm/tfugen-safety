# הגדרת שליחת מיילים מ-Outlook (פעם אחת בלבד)

הקוד מוכן. נשאר לתת לאפליקציה הרשאה ב-Azure לשלוח מיילים מהחשבון שלך.

## שלב 1 — Azure Portal: הוספת הרשאת Mail.Send

1. כניסה ל-https://portal.azure.com (אותו חשבון Microsoft שמחובר ל-OneDrive)
2. בחיפוש למעלה: **App registrations** → לבחור את האפליקציה שיצרת ל-Tapugan
3. בתפריט הצד: **API permissions**
4. **+ Add a permission** → **Microsoft Graph** → **Delegated permissions**
5. בחיפוש: **Mail.Send** → לסמן ולהוסיף
6. אם הכפתור **"Grant admin consent for [Tenant]"** קיים — ללחוץ עליו ולאשר. (אם לא קיים → לדלג, זה אומר שכבר אושר אוטומטית.)
7. ✅ אמורים לראות `Mail.Send` ברשימה עם סטטוס "Granted"

## שלב 2 — באפליקציה: התחברות מחדש

לחיבור הקיים אין עדיין את ההרשאה החדשה — צריך טוקן טרי שכולל אותה.

1. פתחי את האפליקציה — **תפריט … → ☁️ חיבור OneDrive (סנכרון מסמכים)**
2. לחיצה על **התנתק** (כפתור אדום)
3. לחיצה על **☁️ התחבר / זהו חשבון אחר**
4. ייפתח חלון Microsoft שיבקש אישור — תופיע שורה חדשה: **"Send mail as you"** → לאשר
5. החלון ייסגר, ה-OneDrive יחזור להיות מחובר

## שלב 3 — בדיקה

בתוך אותו תפריט (חיבור OneDrive) תופיע סקציה חדשה:

> 📧 דוחות מייל
>
> [📧 שלח דוח לעצמי עכשיו]

לחיצה תשלח ל-mail שלך דוח HTML עם:
- משימות באיחור
- משימות עד 7 ימים
- בדיקות ציוד עם תוקף עד 30 יום
- PPE עם תוקף עד 30 יום
- הדרכות עם תוקף עד 30 יום
- NCRs פתוחים (עד 30 ראשונים)

המייל מגיע מהחשבון Outlook שלך לעצמך (דרך Microsoft Graph API) — לא דרך שרת חיצוני.

## שלבים הבאים (אחרי שזה רץ)

1. **שליחה לאחראי משימה** — כשמשימה נפתחת/מתעדכנת, שולחים מייל ל-`assignee` שלה.
2. **לוח זמנים אוטומטי** — Cloudflare Worker שרץ כל בוקר ב-7:00 ושולח את הדוח אוטומטית.

שני השלבים האלה תלויים בכך ששלב 1+2 כאן עבדו תקין.

## אם משהו נכשל

- **"sendMail 401"** = ה-token לא כולל Mail.Send. לוודא שהוספת ב-Azure ולעשות התנתק→התחבר שוב.
- **"sendMail 403"** = החשבון שלך לא מורשה לשלוח (נדיר — קורה ב-tenants עם מדיניות מחמירה). צריך admin consent.
- **"לא מצאנו את המייל שלך"** = `/me` API לא החזיר mail. נדיר — סימן שאין לחשבון Outlook box. נצטרך לעבור לסנמן ידני.
