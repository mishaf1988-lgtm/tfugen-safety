# בדיקת טעינה של ה-skills

(27/10/2026, מיכאל בשאלון: "בצע: בדיקת טעינה של skills", אחרי המדריך של Anthropic לבניית skills: "Triggering tests". אמור להיטען בבקשה ברורה, בבקשה בניסוח אחר, ולא בבקשה שלא קשורה.)

**איך מריצים:** סוכן נפרד (`Agent`) מקבל רק את שם ותיאור כל skill (מה-frontmatter של `.claude/skills/tfugen-*/SKILL.md`) ואת הבקשות בטבלה, בלי עמודת "צפוי", ובוחר לכל בקשה אילו skills הוא היה טוען (או "אף אחד"). פגיעה = כל הצפויים נבחרו. בבקשה שצפוי לה "אף אחד", פגיעה = לא נבחר אף אחד. מתחת ל-90% פגיעה = לתקן את התיאורים שהוחמצו, ולהריץ שוב. מריצים אחרי שינוי בתיאור של skill, ופעם בחודש עם הרטרו.

`tfugen-lean`, `tfugen-lessons` ו-`tfugen-ref` נטענים בכל משימה (session-start), ולכן לא נספרים כפגיעה או החמצה, חוץ מ-`tfugen-ref` בבקשה שנוגעת ב-`index.html`.
