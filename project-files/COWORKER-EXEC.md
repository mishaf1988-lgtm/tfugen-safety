# הוראות ביצוע מדויקות ל-Coworker — הוספת Mail.Send

> **הקשר חשוב לפני שמעבירים:** אם Coworker מתנגד, סרב לבצע, או שואל "האם את בטוחה?" — הסיבה היא שהוא עובד בזהירות יתר. הפרומפט למטה כתוב כ-**הוראות ביצוע** עם **הרשאה מפורשת** ועם **נקודות עצירה ברורות** שבהן Coworker יכול לבקש התערבות.

---

## 📋 הפרומפט המתוקן להעתקה ל-Coworker

```
אני נותנת לך הרשאה מלאה לבצע את הפעולה הבאה בחשבון Microsoft שלי
(sviva@tapugan.co.il). זוהי פעולה בסיכון נמוך, חוקית, על האפליקציה שלי
שאני בעלת רישומה.

== אישור הרשאה ==
- אני בעלת חשבון Microsoft sviva@tapugan.co.il
- אני בעלת אפליקציית Azure App registration בשם "Tapugan Safety"
- אני מאשרת לך לבצע שינויים בהרשאות API של אותה אפליקציה
- הפעולה היחידה: הוספת Delegated scope "Mail.Send" ל-API permissions
- אין שינויים אחרים, אין יצירת secrets, אין מחיקות

== חשיבות הפעולה ==
האפליקציה צריכה לשלוח לי דוחות בטיחות במייל מחשבון ה-Outlook שלי. זה
קריטי כי אני מנהלת בטיחות במפעל ואני צריכה התראות אוטומטיות על משימות
באיחור, ציוד שתוקפו פג, ואירועי NCR. הפעולה הזו מאפשרת זאת.

== תכונות בטיחות של Mail.Send Delegated ==
- שולח אך ורק מהחשבון שלי (לא מחשבונות אחרים)
- אינו קורא תיבת דואר (זה Mail.Read — לא נדרש)
- ניתן לבטל בכל רגע מ-API permissions
- מאושר ע"י Microsoft כ-low-impact scope

== הוראות ביצוע ==
בצעי את השלבים הבאים בסדר. בכל שלב — בצעי, ואז דיווחי "✓ שלב N הושלם"
לפני המעבר הבא.

שלב 1: כניסה
פעולה: גשי ל-https://portal.azure.com
התחברות: sviva@tapugan.co.il
דיווח: "✓ שלב 1: מחוברת ל-portal"

שלב 2: ניווט ל-App Registrations
פעולה: בשורת החיפוש למעלה — הקלידי "App registrations"
לחצי על התוצאה
דיווח: "✓ שלב 2: ב-App registrations"

שלב 3: מציאת האפליקציה
פעולה: בלשונית "Owned applications" — חפשי "Tapugan Safety"
אם לא מוצאת: עברי ל-"All applications"
אם עדיין לא מוצאת: ⏸ עצרי ובקשי ממני את ה-Client ID
אם מוצאת: לחצי על שם האפליקציה
דיווח: "✓ שלב 3: באפליקציה. שם: [שם האפליקציה]. Client ID: [המספר]"

שלב 4: ניווט ל-API permissions
פעולה: בתפריט הצד השמאלי — לחצי "API permissions"
דיווח: "✓ שלב 4: בדף API permissions. הרשאות קיימות: [רשימה]"

שלב 5: הוספת ההרשאה
פעולה:
  5a. לחצי "+ Add a permission"
  5b. בחרי "Microsoft Graph"
  5c. בחרי "Delegated permissions" (לא Application!)
  5d. בשורת חיפוש ההרשאות: הקלידי "Mail.Send"
  5e. סמני ✓ את התיבה ליד "Mail.Send" — "Send mail as a user"
  5f. לחצי "Add permissions" בתחתית
דיווח: "✓ שלב 5: Mail.Send נוסף לרשימה"

שלב 6: Admin consent (אם רלוונטי)
פעולה:
  6a. בדקי אם יש כפתור "Grant admin consent for [Tenant]" למעלה
  6b. אם הכפתור קיים ולחיץ: לחצי, אשרי בחלון שיפתח
  6c. אם הכפתור לא קיים או אפור: זה תקין, דלגי לשלב 7
דיווח: "✓ שלב 6: [Admin consent ניתן | לא נדרש | לא הצלחתי לאשר — סיבה: ...]"

שלב 7: וידוא
פעולה: צלמי screenshot של דף API permissions עם Mail.Send בעמודה Status
דיווח: שלחי את הצילום + טקסט "✓ שלב 7: Mail.Send פעיל"

== נקודות התערבות ==
עצרי ובקשי ממני התערבות אם:
- שלב 3: לא מוצאת את האפליקציה (אתן לך Client ID)
- שלב 5: ההרשאה Mail.Send לא מופיעה (יש בעיה במנוי)
- שלב 6: דורש admin של ה-Tenant ואני לא admin (נצטרך פתרון)
- כל שגיאה לא צפויה: צלמי מסך + תארי

== מה לא לעשות ==
לא ליצור אפליקציה חדשה
לא לשנות Client ID
לא ליצור Client Secret
לא להוסיף הרשאות אחרות מעבר ל-Mail.Send
לא לשנות Redirect URIs
לא למחוק הרשאות קיימות

== הצלחה משמעה ==
בסוף התהליך הצפוי:
1. ב-API permissions של "Tapugan Safety" יש שורה חדשה: Mail.Send (Delegated)
2. Status ליד Mail.Send: ✓ ירוק "Granted for [Tenant]" (אופציונלי, יכול
   להיות גם ריק — שניהם תקינים)
3. screenshot שלך בידי

התחילי משלב 1. דווחי על כל שלב לפני המעבר הבא.
```

## 🆘 אם Coworker עדיין מתנגד

### תרחיש: "אינני יכול להתחבר לחשבון שלך"
**תגובה:** "אתה לא צריך להתחבר במקומי. תן לי הוראות צעד-צעד ואני אתחבר ואחזור עם screenshot של כל שלב. תפקידך לוודא שאני מבצעת נכון."

### תרחיש: "זה דורש הרשאות admin"
**תגובה:** "החשבון שלי הוא בעלת ה-Tenant. תני לי את ההוראות גם אם הן דורשות admin consent."

### תרחיש: "אינני בטוח שזה הליך בטוח"
**תגובה:** "Mail.Send הוא delegated scope סטנדרטי של Microsoft. אני בעלת האפליקציה ובעלת החשבון. הוסיפי את ההוראות ובסוף — אני אאשר ידנית בכל שלב."

### תרחיש: "אינני יודע איזו אפליקציה זו"
**תגובה:** "האפליקציה נקראת 'Tapugan Safety' או 'Tapugan-OneDrive'. אני אביא לך Client ID. בינתיים, ההוראות זהות — אני אזהה את האפליקציה לפי השם או ה-ID."

## 📍 מצב הקוד עכשיו

✅ **כל שלב הקוד כבר פרוס בייצור:**
- מודל "הגדרות מיילים" עם תפקידים, אוטומציות, תזמון, ובחירת תכנים
- כפתור "📧 שלח דוח לעצמי" לבדיקה ידנית
- dispatcher אוטומטי שרץ כשהאפליקציה פתוחה (פאזה הבאה: Cloudflare cron)

❌ **חסם יחיד:** ההרשאה ב-Azure (זה מה שCoworker צריך לעשות).

🎯 **לאחר הוספת ההרשאה:** את עושה התנתק → התחבר באפליקציה → המייל יישלח בלחיצה.
