## ⏳ סוכן 2 — Inbox איפוסי סיסמה (קוד פרוס, צריך migration)

**מטרה:** עובד שוכח סיסמה → לוחץ "שכחתי סיסמה" → הבקשה נכנסת לרשימה אצל המנהל → המנהל לוחץ "אשר ושלח" → סיסמה חדשה מיוצרת ונשלחת אוטומטית במייל+WhatsApp.

### 🛠 פעולה ידנית במחשב מחר

1. פתחי [Supabase Dashboard](https://supabase.com/dashboard/project/znhjtpcltrxxyfjczgvw)
2. **SQL Editor → New query**
3. העתיקי את כל התוכן של `migrations/2026-05-09_password_reset_requests.sql`
4. הריצי. צפוי: `Success. No rows returned`
5. אישור: כניסי ל-**Table Editor** וודאי שטבלת `password_reset_requests` קיימת

### בדיקה אחרי הרצת ה-migration

1. **כעובד שוכח סיסמה:**
   - מסך login → "שכחתי סיסמה?" → מזין username → "📱 שלח למנהל"
   - Toast חדש: "✓ הבקשה נשלחה למנהל. תקבל/י סיסמה חדשה תוך מספר דקות"
   - **ב-DB:** שורה חדשה ב-`password_reset_requests` עם status='pending'
2. **כאדמין:**
   - פתח את הדשבורד
   - **כרטיס צהוב חדש:** "🔒 בקשות איפוס סיסמה (1)"
   - לחיצה על "✅ אשר ושלח" → `/api/reset-password` נקרא → modal פרטי כניסה נפתח → `_credAutoDeliver` מפעיל מייל+WhatsApp אוטומטית
   - השורה ב-DB עוברת ל-status='completed' עם `approved_by` ו-`approved_at`

## 🔮 סוכן 3 — Microsoft Graph CLIENT_CREDENTIALS (אופציה C עתידית)

לאוטומציה מלאה של איפוס סיסמה — **שליחת מייל גם כשהאדמין לא מחובר**.

**מצב:** לא הוטמע (סוכן 2 פותר את הצורך הקצוב באישור ידני בלחיצה אחת).

**אם תרצי בעתיד:**
1. ב-Azure Portal — Tapugan Safety App registration
2. **API permissions** → "Application permissions" → Microsoft Graph → `Mail.Send`
3. **Grant admin consent** (כן, לזה יש צורך ב-admin)
4. **Certificates & secrets** → New client secret → 12 months
5. שמרי את הסוד ב-Cloudflare Pages env: `AZURE_CLIENT_ID`, `AZURE_TENANT_ID`, `AZURE_CLIENT_SECRET`
6. צרי `/functions/api/send-recovery-auto.js` שמשתמש ב-CLIENT_CREDENTIALS לקבל token ושולח מייל בעצמו
7. עדכון `_forgotPwSendWa` לקרוא לendpoint הזה ישירות → אין צורך באישור ידני

**זמן בנייה:** ~2-3 שעות אחרי שההגדרות ב-Azure מוכנות.
