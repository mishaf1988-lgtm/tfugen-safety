# Lessons

מיכאל ביקש ב-01/10/2026: ללמוד מטעויות, ולרכז אותן במקום אחד קצר.

## הכלל הקבוע (מיכאל, 01/10/2026: "כן")

**אחרי כל טעות שמתגלה, של Claude או של מיכאל: לקח חדש בקובץ הזה, באותו PR של התיקון.**
לא PR נפרד, ולא "אוסיף אחר כך".

- לכל לקח: מה קרה (תאריך, PR), איך התגלה, הכלל מעכשיו, ואיך נאכף.
- **אם אפשר לאכוף בקוד, להציע hook או בדיקה.** "קוד לא שוכח"; טקסט נשכח אחרי compaction.
- "נאכף: טקסט בלבד" = הכלל תלוי בכך שמישהו יקרא את הקובץ הזה. זה המצב החלש.
- לקח שכבר כתוב ב-STATUS / DECISIONS נכנס גם לכאן, בקצרה. כאן מרוכז, שם מפורט.

## לקחים

### מיזוג ובדיקות

**1. מיזוג בלי harness מלא (#994, 01/10/2026).**
מה קרה: migration של ניקוי משתמשים אנונימיים מוזג בלי הרצת כל הבדיקות, ו-`rls-policy-test.mjs`
נכשל עליו (DELETE בלי ציון אישור בקובץ). התגלה: בריצה הבאה של ה-harness.
הכלל: אין מיזוג בלי בדיקת `tests` ירוקה ב-GitHub, גם כשהשינוי "רק migration".
נאכף: `.github/workflows/tests.yml` על כל PR + `.claude/hooks/merge-gate.py` חוסם `merge_pull_request` (#1006).

**2. נכשל ב-GitHub ועבר מקומית (#1006, 01/10/2026).**
מה קרה: שלושה הבדלי סביבה, לא באג ולא "flake": `requests` חסר ל-Python, playwright חדש יותר
(ראה 0 מפרידים בתפריט ב-`backlog-visual-test`), ומכונה איטית יותר. התגלה: הריצה הראשונה ב-GitHub.
הכלל: כשנכשל רק במקום אחד, למצוא את ההבדל (גרסה, חבילה, מהירות). לקבע גרסאות. "flake" אינו סיבה.
נאכף: חלקית. playwright מקובע ל-1.56.1 ו-`pip install requests` ב-`tests.yml`. השאר טקסט.

**3. עריכת בדיקה בזמן שה-harness רץ (#1002, 01/10/2026).**
מה קרה: `backup-od-test.mjs` עודכן באמצע ריצה, וה-harness דיווח כישלונות מדומים (6 failed).
התגלה: הבדיקה עברה בהרצה חוזרת לבד.
הכלל: לא לערוך קוד או בדיקות עד שהריצה מסתיימת. אם ערכת, להריץ שוב לפני שמסיקים משהו.
נאכף: טקסט בלבד.

**4. `expectedHeadSha` מקוצר (#1008, 01/10/2026).**
מה קרה: GitHub דורש sha מלא (40 תווים), וה-hook השווה sha מקוצר למלא ולכן חסם מיזוג תקין.
התגלה: המיזוג נכשל.
הכלל: לא להעביר `expectedHeadSha` מקוצר ל-`merge_pull_request`. בלי השדה זה עובד.
נאכף: ה-hook תוקן להשוות לפי תחילית (#1008). העברת sha מקוצר ל-GitHub עצמו: טקסט בלבד.

**5. דילוג "רק .md" לא עבד על שם קובץ בעברית (#1009, 01/10/2026).**
מה קרה: `git diff --name-only` מחזיר שם עם עברית במירכאות ועם `\327...`, ולכן `\.md$` לא זיהה
את `handoff-01-10-2026-ערב.md`, ו-PR של תיעוד בלבד הריץ את כל הבדיקות. התגלה: מיכאל ראה ש-#1009 רץ דקות.
הכלל: כל `git diff` / `git ls-files` שמסננים את הפלט שלו: `git -c core.quotepath=off`.
נאכף: תוקן ב-`tests.yml` (ה-PR של הקובץ הזה). שוחזר מקומית לפני ואחרי.

**6. יותר מדי PRs קטנים (#1003 עד #1005, 01/10/2026).**
מה קרה: חמישה PRs רק לעדכוני STATUS, וכל סבב בדיקות כ-4 דקות.
הכלל: התיעוד (STATUS, DECISIONS, הלקח פה) נכנס לאותו PR של השינוי.
נאכף: טקסט בלבד. (תיעוד שכולו `.md` עובר מהר מאז לקח 5, אבל עדיין PR נוסף.)

### בדיקות שבודקות את הדבר הנכון

**7. בדיקת XML לפי חלון טקסט במקום לפי מבנה (#1008, 01/10/2026).**
מה קרה: `addPictures` בדק אם `xmlns:r` מופיע ב-800 התווים הראשונים במקום בתגית השורש. ה-xlsm נפתח
"פגום" ו-Excel הסיר את `drawing2.xml` (התמונות בעמודה P). התגלה: מיכאל פתח את הקובץ.
הכלל: לבדוק מבנה (התגית, האלמנט, התכונה בתגית), לא "מופיע איפשהו בהתחלה".
נאכף: `rootHasR` + בדיקה בסגנון Excel ב-`hazard-file-test.mjs`.

### מקומות משותפים

**8. תיקייה חדשה ב-OneDrive בלי לבדוק מי מנקה שם (#1002, 01/10/2026).**
מה קרה: `monthly` ו-`photos` נוספו תחת `_Backups`, וניקוי הגיבויים בדפדפן היה מוחק אותן.
התגלה: לפני שקרה, בסקירת הקוד.
הכלל: לפני כתיבה למקום משותף (תיקייה, bucket, טבלה), `grep` על כל מי שכותב ומוחק שם.
נאכף: `backup-od-test.mjs` בודק שהניקוי לא נוגע ב-`monthly` ו-`photos`.

### טענות וממצאים

**9. 375 שורות ב-`ncr` (09/2026).**
מה קרה: CLAUDE.md טען 375 רשומות בייצור בלי מדידה, ואחר כך תוקן לטענה שגויה אחרת.
בפועל `public.ncr` = 0 (איפוס מכוון 18/09) ו-375 בגיבוי. התגלה: מדידה ב-22/09.
הכלל: מספר על נתונים חיים נכתב רק אחרי `count` אמיתי, עם תאריך המדידה.
נאכף: טקסט. המחיקה עצמה חסומה ב-`guard-sql.py`. פירוט: skill `tfugen-history`.

**10. שלוש התנגשויות בין שני החשבונות (22/09/2026).**
מה קרה: PR אחרי 31 commits על main, עריכות STATUS על עוגנים שהשתנו, ו"ממצא" שהצד השני כבר סגר.
הכלל: `fetch` + `reset --hard origin/main` לפני כל עריכה; `grep` ב-STATUS לפני דיווח ממצא.
נאכף: טקסט (חוקי הסנכרון ב-CLAUDE.md). פירוט: skill `tfugen-history`.

**11. "החלון נעלם" (01/10/2026).**
מה קרה: חלון "שנה סיסמה" נסגר אחרי כ-4 שניות. נחקר כבאג; בפועל Claude in Chrome שלח Esc.
התגלה: אחרי שכל מסלול באפליקציה נשלל ב-Playwright.
הכלל: כשהבדיקה נעשית דרך כלי אוטומציה, לשלול קודם את הכלי עצמו.
נאכף: `changepw-wrong-test.js` (#992) מוכיח שהאפליקציה לא סוגרת את החלון.

**12. "ההתראה לא הגיעה" (30/09/2026).**
מה קרה: התראת נ-6 דווחה כלא הגיעה; ב-DB `notified_at` מלא ו-`sent` מ-Meta ומ-Outlook.
מיכאל: "טעות שלי הכל הגיע". התגלה: בדיקת ה-DB לפני תיקון.
הכלל: לפני "תיקון" התראה, לבדוק `notified_at` ויומן ההתראות. "נשלח" = הספק קיבל, לא "נמסר".
נאכף: טקסט בלבד.
