# Safety Platform

מערכת לניהול בטיחות ואיכות סביבה במפעל (ISO 45001, ISO 14001): מסמכים ותפוגות, ביקורות, NCR,
אירועים, הדרכות, סקרי סיכונים, היתרי עבודה, ציוד מגן, ציוד בבדיקה, חומרים מסוכנים ופסולת.

- **אפליקציה:** קובץ אחד, `index.html`, בלי build.
- **שרת:** Cloudflare Pages Functions (`functions/`).
- **מסד:** Supabase.

## מפעל חדש

1. ממלאים את `functions/_site.js`: שם, מנהל, כתובת האתר, המסד, דומיין הכניסה ומיילים.
2. מחליפים את `logo.jpg` בלוגו של המפעל, ומריצים `python3 tools/make-logo.py`.
3. מריצים `node tests/harness/site-config-test.mjs --write`. הפקודה כותבת את ההגדרות לדף, לשם
   האפליקציה ולאייקון. אחר כך מריצים את אותה בדיקה בלי `--write`, והיא צריכה לעבור.

## המסד

`db/schema.sql` מקים מסד ריק: 56 טבלאות, הרשאות (RLS), פונקציות, טריגרים, שני מאגרי קבצים ומשימות מתוזמנות. בלי שורות.

1. פרויקט חדש ב-Supabase. ב-SQL Editor מדביקים את כל הקובץ ומריצים פעם אחת.
2. הסוד שהמסד שולח לאתר, אותו ערך כמו `TRUSTEE_NOTIFY_SECRET` באתר: `select vault.create_secret('<הערך>', 'trustee_notify_secret');`
3. כתובת האתר ודומיין הכניסה בקובץ הם אלה של `functions/_site.js`. שיניתם שם? מחליפים גם בקובץ.
4. ב-Authentication יוצרים את `admin@<דומיין הכניסה>`, האדמין הראשון.

## הסוכנים

`agents/`: ארבעה סוכנים שרצים לבד (דוח ציות, מגמות, מפקח מדומה, הדרכה שבועית מהשטח). ההקמה: `agents/README.md`.

המדריך המלא להקמת האתר יתווסף בשלב הבא.
