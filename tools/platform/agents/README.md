# הסוכנים

ארבעה סוכנים שרצים לבד בזמנים קבועים (Routines של Claude Code), וקוראים רק מהמסד של האפליקציה דרך השרת שלה.
אף סוכן לא שולח מייל ולא מוחק. מה שהם מוצאים מגיע להודעה האחרונה בשיחה של הסוכן, ושורה אחת מכל ריצה מגיעה למייל השבועי (`agent_log`).

## הקמה

1. **מפתח לסוכנים:** מחרוזת אקראית ארוכה. באתר (Cloudflare Pages > Settings > Variables) בשם `ROUTINE_KEY`, ובסביבה של Claude Code שבה הסוכנים רצים, כמשתנה סביבה באותו שם.
2. **הבדיקה:** בתיקיית ה-repo, `bash agents/routine-db.sh '{"op":"state_get","keys":["agent_log"]}'` מחזיר `"ok":true`. יציאה 3 = אין מפתח בסביבה. יציאה 4 = המפתח לא תואם לאתר, או שהאתר לא זמין.
3. **סוכן:** ב-claude.ai > Code > Routines, Routine חדש על ה-repo הזה, בזמן שבטבלה, עם הפרומפט:
   `git fetch origin main && git checkout -B main origin/main. קרא את agents/<קובץ> ובצע את הפרומפט שבין שני הקווים '---', מההתחלה.`
   כך שינוי בהוראות הוא שינוי בקובץ בלבד, בלי לגעת ב-Routine.
4. **ריצת ניסיון:** "Run now" פעם אחת לכל סוכן, ולבדוק שהשורה שלו הגיעה: `bash agents/routine-db.sh '{"op":"state_get","keys":["agent_log"]}'`.
