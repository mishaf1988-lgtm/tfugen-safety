מדיניות פרטיות — Tapugan Safety

תאריך עדכון אחרון: 4 במאי 2026

1. מי אנחנו

Tapugan Safety היא מערכת ניהול בטיחות ואיכות סביבה פנים-ארגונית של תפוגן בע"מ. המערכת זמינה בכתובת https://tapugan-safety.pages.dev.

2. אילו נתונים נאספים

  • נתוני בטיחות פנים-ארגוניים שהמשתמש מזין: דיווחי אי-התאמה, סקרי סיכונים, תפוגות ציוד, סבבים, הדרכות.
  • פרטי משתמש: שם, תפקיד, כתובת אימייל, מספר טלפון (לצורך התראות פנימיות בלבד).
  • נתוני שימוש טכניים: לוגים של פעולות במערכת לצורכי audit (ISO 45001 §7.5).

3. למה משמשים הנתונים

  • ניהול מערך הבטיחות לפי תקני ISO 45001 ו-ISO 14001.
  • שליחת התראות WhatsApp/אימייל למשתמשים פנימיים בלבד (NCR קריטי, משימה בפיגור, תפוגה).
  • היסטוריית שינויים לצורכי ביקורת רגולטורית.

4. שיתוף עם צד שלישי

הנתונים נשמרים ב-Supabase ו-Cloudflare כספקי תשתית. לא מועברים לצד ג' שיווקי. לא נמכרים. לא משמשים לפרסום.

5. שירותי WhatsApp

השליחה דרך WhatsApp Business Cloud API (Meta) משמשת אך ורק לצורכי תפעול פנים-ארגוני. נשלחים מסרי תבנית מאושרים בלבד או הודעות עוקבות לשיחה שהתחיל המשתמש.

6. שמירה ומחיקה

נתוני בטיחות נשמרים לפי דרישות הרגולציה (לרוב 7 שנים). בקשת מחיקה — ראה סעיף 7.

8. אבטחה

  • גישה ל-API מוגנת ע"י Row-Level Security של Supabase.
  • סודות (tokens, API keys) נשמרים כ-environment variables בלבד, לא ב-git.

Privacy Policy — Tapugan Safety

Last updated: 2026-05-04

1. Who We Are

Tapugan Safety is an internal safety and environmental management system operated by Tapugan Ltd. (Israel). Available at https://tapugan-safety.pages.dev.

2. Data Collected

  • Internal safety data entered by users: non-conformance reports, risk assessments, equipment expiries, rounds, training records.
  • User profile data: name, role, email, phone number (for internal notifications only).
  • Technical usage logs: action audit trail required by ISO 45001 §7.5.

3. How We Use the Data

  • Operate the safety management system per ISO 45001 and ISO 14001 standards.
  • Send WhatsApp/email notifications to internal users only (critical NCR, overdue task, expiry).
  • Maintain change history for regulatory audit.

4. Third-Party Sharing

Data is stored on Supabase and Cloudflare as infrastructure providers. No data is sold or shared with third-party marketers, used for advertising, or otherwise repurposed.

5. WhatsApp Service

Messages sent via the WhatsApp Business Cloud API (Meta) are strictly for internal operational use. Only Meta-approved template messages or follow-up messages within an active user-initiated conversation are sent.

6. Retention & Deletion

Safety data is retained per regulatory requirements (typically 7 years). For deletion requests see section 7.

7. Data Deletion Request

To request deletion of your personal data, contact mishaf1988@gmail.com with subject line "Tapugan Safety — Data Deletion". Confirmation will be sent within 30 days. See also User Data Deletion Instructions.

8. Security

  • HTTPS for all transport.
  • API access protected by Supabase Row-Level Security.
  • Secrets (tokens, API keys) stored only as environment variables, never in git.

9. Policy Updates

Material changes will be emailed to system users.
